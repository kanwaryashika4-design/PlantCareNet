About Plant Care Net

Architecture, methodology, datasets, and performance benchmarks

💡 Overview

Plant Care Net is a multimodal AI platform for tomato plant health assessment, combining deep learning image classification, computer vision-based severity quantification, and tabular machine learning for nutrient deficiency analysis — all accessible through a unified web interface designed for both field farmers and agricultural researchers.

⚙️ Severity Quantification Pipeline Methodology

The severity scoring engine operates completely without a second ML model. Instead, it uses classical computer vision algorithms directly running on CPU:

1
RGB → HSV Color Conversion

Image matrix is shifted to HSV. Splitting color values (hue) from lighting dynamics stabilizes structural threshold operations perfectly compared to native RGB arrays.

2
Dual Space Masking

Calculates two independent matrix indices: full leaf parameter contour and a healthy green space layer matrix (Hue threshold 35–85 on standard limits).

3
Pixel Area Analysis

Evaluates leaf tissue degradation directly: infected area matrix equals total leaf space count minus the isolated healthy components. Runs instantly on CPU vectors.

4
Threshold Bucket Allocation

Bins result metrics across three scales: 0–20% (Mild profile), 21–50% (Moderate profiling), and 51–100% (Severe infection profiles).
